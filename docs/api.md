# API Reference

Shrinkage estimators for covariance matrices (Ledoit–Wolf).

```python
from shrinkage.linear import cov1para
from shrinkage.nonlinear import nonlinear_shrinkage
```

Both estimators are also re-exported from the package root, so
`from shrinkage import cov1para, nonlinear_shrinkage` is equivalent.
